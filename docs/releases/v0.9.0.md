# v0.9.0 Release Checkpoint

## 목적

`v0.9.0`은 Single EC2 기반 배포 구조가 성립한 시점을 기록하기 위한 태그다.

## 완료된 범위

- Single EC2 인스턴스 배포
- Docker Compose 기반 서비스 실행
- Nginx Reverse Proxy 구성
- 개발/운영 Compose 환경 분리

## 포함하지 않는 범위

- Terraform `user_data` 기반 자동 부트스트랩
- 완전한 재현 가능 프로비저닝
- RDS 분리
- CI/CD
- CloudWatch
- ALB / Auto Scaling

## 다음 목표

`v1.0.0`에서는 Terraform apply만으로 EC2 환경이 구성되고 애플리케이션이 실행되는 재현 가능한 배포 구조를 목표로 한다.
