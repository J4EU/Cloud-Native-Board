# v1.0.0 Release Checkpoint

## 목적

`v1.0.0`은 Single EC2 기반 배포 구조를 재현 가능한 형태로 정리한 시점을 기록하기 위한 태그다.

## 완료된 범위

- Terraform 기반 EC2 프로비저닝
- `user_data` 기반 EC2 초기 부트스트랩
- Docker / Docker Compose 설치 자동화
- 애플리케이션 Repository clone 자동화
- `.env` 파일 생성 흐름 정리
- Docker Compose 기반 서비스 실행
- MariaDB 초기화 스크립트 자동 실행
- Nginx Reverse Proxy 구성
- Single EC2 환경에서 애플리케이션 실행 확인

## 포함하지 않는 범위

- Secret 완전 자동 주입
- SSM Parameter Store 연동
- Secrets Manager 연동
- RDS 분리
- CI/CD
- CloudWatch
- ALB / Auto Scaling
- HTTPS

## 수동 작업으로 남긴 범위

- 민감 정보 값 관리
- 배포 전 환경 변수 확인
- 필요 시 EC2 내부 상태 점검

## 주요 결정

- EC2 초기 환경 구성은 Terraform `user_data`를 사용한다.
- DB 초기화는 MariaDB 공식 이미지의 `/docker-entrypoint-initdb.d` 흐름을 사용한다.
- Secret 자동 주입은 `v1.0.0` 범위에서 제외한다.
- `v1.0.0`은 완전한 운영 환경이 아니라, Single EC2 배포 재현성을 확보하는 단계로 정의한다.

## 다음 목표

`v1.1.0`에서는 SSM 기반 운영 접근 또는 Secret 관리 개선을 목표로 한다.
