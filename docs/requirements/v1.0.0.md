# v1.0.0 Requirements

## 목표

단일 EC2 환경에서 F1 Board를 재현 가능하게 Bootstrap한다.

### 핵심 목표

- EC2 초기 설정 자동화
- Docker 실행 환경 자동 구성
- Repository 자동 동기화
- 비민감 env 템플릿 자동 생성
- Docker Compose 최초 실행 시 DB 초기화

### 자동화 범위에서 제외

- Secret 자동 주입
- Compose 자동 실행

---

## Bootstrap 흐름

```
Terraform
→ EC2 생성
→ user_data 실행
→ Docker / Compose / Buildx 설치
→ Repository clone
→ env 템플릿 생성
→ EC2 SSH 접속
→ user-data.log 검증
→ 수동 Secret 주입
→ Docker Compose 실행
```

## Requirement 변경 이유

- user_data 스크립트 구현 과정에서 Secret이 평문으로 들어가게 됨
- 이는 보안상 문제가 된다고 판단하여, 완전 자동화보단 수동 주입으로 대체하겠다고 판단
- 추후 `v1.1.0`에서 SSM 도입 예정

---

## 운영 원칙

- user_data 실패 원인을 반드시 추적 가능해야 한다.
- Secret은 Terraform/user_data에 평문으로 포함하지 않는다.
- apply 직후 `/var/log/user-data.log`를 우선 확인한다.
